
# Smart Folders
  - description: A feature that allows users to create and manage smart folders based on specific criteria.
  - The main view of the smart folders tab is a list of smart folders, each with a gear icon.
  - There is a plus button that allows the user to create a new smart folder by specifying criteria (e.g., type (file, folder), location, or name) and a name for the smart folder. The smart folder will automatically update its contents based on the specified criteria and the current state of the file system).
  - You can also manage existing smart folders by editing or deleting them.
    - to manage, show a list of existing smart folders, each with a dots(...) to show menu for editing or deleting that one. The menu contains edit and delete options.  
      - edit opens a dialog to edit the smart folder criteria.
      - deletion: show a confirmation before deleting the smart folder.
        - like folders, smart folders cannot be trashed. Deleting a smart folder will permanently remove it and will not affect the files or folders that it contains.
  
  - Clicking on a smart folder opens it to show its contents, which are the files and folders that match the criteria of the smart folder.
    - Inside this view, the list of files and folders is visually identical to the directory navigation view. Users can interact with the files and folders in the smart folder view just like they would in the directory navigation view, including opening, renaming, moving, and deleting them.
